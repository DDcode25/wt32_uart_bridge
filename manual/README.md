# Руководство по web-интерфейсу

Подробное описание каждой вкладки, каждого поля и того, что происходит при
его изменении.

Интерфейс отдаётся самой платой по её адресу — например `http://192.168.1.50/`
на заводских настройках. Отдельного приложения не требуется, страница целиком
встроена в прошивку.

## С чего начать

Если плата только из коробки — [03. Network](03-network.md), задать адрес.

Если подключаете CRSF — [04. Порты](04-porty.md), раздел про режим CRSF: их
три, и они описывают физически разные схемы.

Если что-то не работает — [09. Как диагностировать](09-diagnostika.md). Там
собраны приёмы, каждый из которых отвечает на вопрос за пару минут и без
осциллографа.
