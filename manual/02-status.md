# 02. Status

Страница обновляется каждую секунду. Ничего не настраивает, кроме кнопок
профилей внизу.

## Система

| Поле | Что означает |
|---|---|
| **Uptime** | время с последней перезагрузки. Сбрасывается в ноль — плата перезагрузилась |
| **Причина перезавантаження** | `power_on` — подали питание, `software` — перезагрузка по команде, `panic` — прошивка упала. Панику стоит смотреть в журнале: там останется, что именно произошло |
| **Вільна пам’ять** | свободная куча сейчас |
| **Мінімум за сесію** | наименьшее значение с момента запуска. Важнее текущего: показывает, насколько близко подходили к пределу |
| **Версія прошивки** | из `git describe`, менять руками нечего |

## Ethernet

**Link**, скорость и дуплекс, **MAC**, **IP**, маска, шлюз, счётчики
**Link up/down**.

Счётчик link down, растущий сам по себе, означает физическую проблему — кабель
или разъём.

## Канали

Карточка на каждый включённый канал. Первым делом — как канал **подключён**:

| Строка | Что означает |
|---|---|
| **Протокол** | что разбирает канал |
| **Режим CRSF** | `RX-only TX16S S.Port`, `Single-wire CRSF` или `Full-duplex CRSF`. Односторонний приём помечен отдельно |
| **Дріт** | выводы, скорость, дуплекс. В однопроводном режиме показан один GPIO |
| **Інверсія** | для общего провода одна на линию, для двух проводов раздельно по направлениям |

Дальше — счётчики.

### Общие

| Строка | Что означает |
|---|---|
| **RX / TX байт** | всего прошло через канал |
| **UART overruns** | приёмный буфер переполнялся: не успели забрать данные |
| **Відкинуто на передачу** | провод медленнее источника, байты выброшены |
| **Заблоковано передач** | попытки записать в канал, которому передавать запрещено (режим RX-only). Не ошибка транспорта, а признак неверной маршрутизации |
| **UDP пакетів rx/tx**, **UDP відкинуто** | сетевой обмен канала |
| **UDP слухач** | `піднято` — сокет открыт. `не піднято — порт зайнятий` означает совпадение портов у двух каналов |
| **Адресати UDP** | куда реально уходит поток. `явних немає` — работает выученный пир |
| **Вивчений пір** | адрес последней входящей датаграммы |
| **Нікуди відправляти** | **красный флаг настройки**: ни адресата, ни пира. Слушающий приёмник сам не пишет, выучить его неоткуда |
| **Watchdog** | `OK` или `таймаут` — данных не было дольше заданного |

### CRSF

**CRSF кадрів**, **кадрів каналів**, **Помилок CRC**, **Помилок синхронізації**,
**Некоректна довжина**, **Failsafe**, **Uplink LQ / RSSI / SNR**, разрез по
типам кадров.

> **Ошибки синхронизации — не показатель здоровья.** На однопроводном CRSF они
> растут примерно на единицу с каждым кадром: в потоке идёт лишний байт между
> кадрами, и разбор его отбрасывает при поиске начала. Судить о линии надо по
> **ошибкам CRC и темпу кадров**.

### Спільний провід

Блок появляется только в однопроводном режиме.

| Строка | Что означает |
|---|---|
| **стан** | `RX_LISTEN` — слушаем, `TX_FRAME` — передаём, `RETURN_TO_RX` — дожидаемся последнего стоп-бита |
| **Кадрів провід rx/tx** | принято чужих и отдано своих |
| **Черга на передачу** | сейчас / максимум за сессию, рядом ёмкость и срок годности |
| **Відкинуто: застаріло** | кадр пролежал дольше срока годности. Линия занята встречным потоком |
| **Відкинуто: переповнення** | провод медленнее источника |
| **Відкинуто: не пройшло перевірку** | из сети пришло то, что нельзя отдавать в шину |
| **Немає вікна для передачі** | момент был занят, кадр остался ждать |
| **Ехо знято / спотворено** | своё эхо, узнанное и не узнанное |
| **Лінію утримано понад норму** | вывод отпущен позже расчётного — на общем проводе это убитый встречный кадр |
| **Найдовший розбір пачки** | сколько заняла обработка. Должно быть заметно меньше межкадрового промежутка |

Отдельно стоит понимать: **растущий счётчик снятого эха на общем проводе —
норма, а не отказ.** Приёмник физически слышит собственный передатчик, и мост
эти кадры отбрасывает, чтобы они не ушли обратно в сеть.

## Потік із мережі

Что пришло с той стороны моста: типы кадров, телеметрия, **Брак із мережі** —
байты, не сложившиеся в целый кадр и потому не отданные в провод.

## Готові профілі

Шесть кнопок. Профиль перезаписывает протоколы, скорости и сетевые режимы
задействованных каналов; **GPIO, адрес платы и пароль не трогает**. Наведение
на кнопку показывает, что именно изменится. Подробности — в основном README,
раздел 7.
