# 03. Network

Адрес самой платы. Меняется **только после перезагрузки**.

| Поле | Что означает |
|---|---|
| **Режим адреси** | статический адрес или DHCP |
| **IP-адреса**, **Маска підмережі**, **Шлюз**, **DNS** | при статическом адресе |
| **Hostname / mDNS** | имя устройства |
| **mDNS увімкнено** | доступность по имени вида `wt32-uartbridge.local` |

## Заводские значения

```
статический адрес, DHCP выключен
IP    192.168.1.50
маска 255.255.255.0
имя   wt32-uartbridge
```

Это важно знать заранее: **при сбросе конфигурации плата уезжает на
192.168.1.50**, а не остаётся там, где была. Так бывает после обновления,
меняющего схему хранения настроек — тогда сохранённая конфигурация не читается
и подставляются заводские значения. Плата, «пропавшая» после прошивки, обычно
находится именно там.

## Если плат несколько

Все они после сброса окажутся на одном и том же адресе. Различать их надёжно
можно только по **MAC** — он виден на вкладке Status в разделе Ethernet и в
`/api/status` полем `ethernet.mac`.

Прежде чем записывать настройки в плату, стоит убедиться, что это та плата: по
адресу этого не понять.

## DHCP

При включённом DHCP плата запрашивает аренду, и если за 30 секунд ответа нет —
возвращается к статическим настройкам из этих же полей. То есть заполнять их
имеет смысл даже когда используете DHCP: это запасной путь, по которому плату
можно найти.
