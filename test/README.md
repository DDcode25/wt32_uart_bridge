# Хостовые тесты протокольной логики

`test_protocols_host.c` содержит копию чистой (не зависящей от ESP-IDF)
логики упаковки/распаковки кадров из `protocol_crsf.c`, `protocol_sbus.c`
и `protocol_mavlink.c`. Тесты запускаются на обычном ПК без железа:

```bash
gcc -Wall -O2 -o test test_protocols_host.c && ./test
```

Результат последнего прогона — `test_log.txt`.

Проверяется:
- CRC8 DVB-S2 на стандартном контрольном векторе ("123456789" -> 0xBC);
- корректность заголовка CRSF-кадра RC_CHANNELS_PACKED;
- round-trip упаковки 16 каналов по 11 бит (CRSF и S.Bus);
- граничное значение 2047 (максимум для 11 бит);
- start/end байты и флаг failsafe в S.Bus;
- расчёт полной длины кадра MAVLink v1, v2 и v2 с подписью.

Это НЕ заменяет проверку на реальном железе — см. раздел
"Что не проверено" в основном README.
