Каналы

Готовые профили

Профиль перезаписывает настройки протоколов и портов всех каналов. GPIO и сетевые параметры не меняются.

Сеть

Изменение IP применяется после перезагрузки. Если адрес задан неверно, доступ к конфигуратору будет потерян — потребуется factory reset через serial.
Доступ по имени: hostname.local

Протоколы по каналам

RAW Transparent не изменяет байты вообще. Остальные режимы также передают поток без изменений — разбор используется только для статистики и отображения каналов.

Направления передачи

Можно сделать канал однонаправленным, отключив одно из направлений (например, только телеметрия наружу).

Диагностика каналов

Логирование

Отключите после отладки: подробный лог влияет на задержку рабочих UART.

Лог устройства

Serial-консоль замолкает, как только канал AUX забирает UART0 — тогда это единственный способ прочитать лог. Начало (старт каналов, передача UART0, получение адреса) закреплено и не вытесняется, далее идут свежие записи.

API устройства

GET открывается по ссылке в новой вкладке. POST вызывается этим интерфейсом или вручную, тело — JSON.

GET/ Этот web-интерфейс
GET/api/status Снимок состояния: система, Ethernet, каналы, счётчики протоколов
GET/api/log Лог устройства: закреплённое начало и свежие записи
GET/api/config Текущая конфигурация в JSON
POST/api/config Записать конфигурацию. Тело — тот же JSON, что отдаёт GET
POST/api/profile {"profile":1} — профили A–D, значения 1…4
POST/api/password {"password":"…"}, минимум 8 символов
POST/api/reboot Перезагрузка устройства, тело не требуется
POST/api/factory {"confirm":"ERASE"} — сброс к заводским настройкам
POST/api/ota Обновление прошивки. Тело — сырой firmware.bin, не JSON и не multipart. Объединённый образ будет отвергнут

Обновление прошивки (OTA)

Загружайте firmware.bin — только приложение. Объединённый firmware_merged.bin не подойдёт: он содержит загрузчик и таблицу разделов, и проверка образа его отвергнет.
Образ пишется в неактивный слот, поэтому текущая прошивка остаётся целой до самого конца. Плата перезагрузится автоматически. Не отключайте питание во время заливки.

Обслуживание

Factory reset требует ввода слова ERASE для подтверждения.
